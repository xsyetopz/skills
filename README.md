My reusable skills for AI coding agents.

- `configure-ci-cd-pipelines`: Write and harden CI workflows safely.
- `create-agent-hooks`: Claude Code and Codex hooks and goals.
- `create-agent-skills`: Write, trim, and evaluate Agent Skills.
- `debug-playstation-emulators`: Debug PCSX2 and DuckStation, patches and logs.
- `debug-software-failures`: Find root causes by repro, bisect, and reduction.
- `design-command-line-interfaces`: Design, change, and rename CLI commands safely.
- `develop-editor-plugins`: Build and test editor extensions and plugins.
- `document-codebases`: README, ARCHITECTURE.md, and GitHub docs.
- `find-vulnerabilities`: Find evidenced vulnerabilities in code and configuration.
- `improve-code-quality`: Find smells, refactor, remove dead shims.
- `manage-git`: Git history, recovery, and GitHub with gh.
- `manage-releases`: Pick SemVer bumps and write changelogs.
- `migrate-js-tooling-to-bun`: Move npm, Yarn, pnpm, and Jest to Bun.
- `optimize-code-performance`: Profile and speed up hot code paths safely.
- `optimize-typescript-builds`: Speed up tsc, tsgo, and type checking.
- `plan-software-changes`: Requirements, design, and checked plans.
- `reverse-engineer-binaries`: Analyze binaries with Ghidra and recover functions.
- `write-agents-md`: Write verified repository instructions for agents.
- `write-behavior-tests`: Behavior tests that fail on real faults.
- `write-justfiles`: Write just recipes that wrap project commands.

## Install

Use the [Vercel Skills CLI](https://skills.sh/docs/cli) with Bun to choose skills interactively:

```shell
bunx skills add xsyetopz/skills
```

Install every skill for every detected agent:

```shell
bunx skills add xsyetopz/skills --all
```

To install globally, add `--global`. To install one skill, use `--skill <name>`.

Update installed skills later with:

```shell
bunx skills update
```
