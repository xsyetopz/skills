# DuckStation resource map

The skill routes to these resource categories: CMake/source build references;
isolated settings and data-directory commands; PS1 executable/disc inputs; BIOS
and region configuration; GDB server; renderer capture; texture replacement;
cheats/patches; save-state compatibility. Read the smallest reference that
matches the current boundary. Use bundled launch or artifact helpers only for
their documented transformation; inspect their arguments and outputs.

No bundled item supplies firmware, copyrighted game data, signing credentials,
or target-hardware proof. A template is output material, not executable
evidence. A script exit code establishes only its explicit checks. The target
repository and the installed DuckStation revision remain authoritative for
options, paths, formats, and supported features.
