# Plan review

## Blocking contract violations

For each demonstrated blocker: affected requirement; plan step; counterexample;
required correction; observation that would validate it. Write “none found” only
for the scope actually reviewed, not as a guarantee of correctness.

## Unresolved dependencies

Name the capability or fact, evidence already checked, and which decision it
changes. Do not invent an owner, approval or date.

## Optional changes

Keep only changes that materially improve the requested result. Distinguish them
from required work. Do not populate this section merely to balance criticism.

## Verdict

State whether the plan is executable under its constraints and which evidence
supports the conclusion. Preserve the original scope and rejected alternatives.
