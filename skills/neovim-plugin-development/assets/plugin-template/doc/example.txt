*example.txt*  Encode buffer lines as JSON

==============================================================================
INTRODUCTION                                                     *example.nvim*

Requires Neovim 0.10.4 or newer. No setup call, dependencies, or default keymaps.
Add this directory to 'runtimepath' or install it through your plugin manager.

COMMAND                                                   *:ExampleJsonLines*

:[range]ExampleJsonLines
        Replace the specified full lines with one JSON array of strings. With
        no range, use the current line. Use % for the whole buffer. Empty lines
        become empty strings. Untouched lines outside the range remain intact.
        One undo reverses the complete command; redo reapplies it.

        The command uses the host JSON encoder. It encodes text, not existing
        JSON values, and does not format or parse a JSON document. A buffer with
        'nomodifiable' rejects edits. 'readonly' prevents ordinary file writes,
        not this in-memory edit. No files are written by the command.

EXAMPLES
>
        :2,4ExampleJsonLines
        :%ExampleJsonLines
<
        To use a keymap, choose your own mapping and bind it explicitly. The
        plugin does not replace user mappings or change filetype options.
